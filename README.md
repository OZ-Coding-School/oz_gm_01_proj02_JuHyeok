게임개발 1기 2차 프로젝트 Personal33 Repository

# 프로젝트 소개
- 모작 게임: 모뉴먼트 밸리
- 장르: 퍼즐
- 프로젝트 규모: 개인

### 📅 개발 기간
2026.01.06 ~ 2026.01.26

### ⚙️ 개발 환경
- Unity6 / 6000.0.66f2
- Visual Studio 2022
- Window 11

## 주요 기능
### 1. 길찾기 알고리즘

- BFS 알고리즘 활용
- 이동 시작 노드와 목표 노드 사이의 경로 반환

### 2. 경로 설정 시스템

- 착시 지점 간 연결을 위해 WorldToScreenPoint 기능 활용
- 착시 여부 체크 매니저
- 노드 인스턴스 내 착시 경로 정보 포함

### 3. 스테이지 동적 생성

- 스테이지 이동, Scene Load 감지
- 각 스테이지 별 배경, 카메라 인스턴스 초기화
- 스테이지 배치
- 플레이어 위치, 초기 노드 경로 설정

### 4. 조작 가능 오브젝트

- Rotator, Slider 오브젝트
- 열거형 축 정보 설정, 동작 방식 구분
